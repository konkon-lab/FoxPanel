# 小鹤双拼

小鹤双拼语言组件：只带一个 rime 方案文件 `rime/xiaohe.schema.yaml`，词库用内置的四叶草拼音；输入串显示成全拼；简体 / 繁体两种模式。

来源和许可证：方案文件里的小鹤双拼拼写规则取自 [rime-double-pinyin](https://github.com/rime/rime-double-pinyin)(LGPL-3.0)，写进了这份以四叶草拼音为词库的方案里；词库依赖 [四叶草拼音](https://github.com/fkxxyz/rime-cloverpinyin)(LGPL-3.0)。方案文件按 LGPL-3.0 发布，许可证全文见 `LICENSE`，它引用的 GPL 第 3 版全文见 <https://www.gnu.org/licenses/gpl-3.0.txt>。

语言组件的格式见 [组件格式 · 语言](../../docs/components.md#语言)。
