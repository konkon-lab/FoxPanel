# 时钟

面板组件(`kind: panel`)：一块只有自己的面板，显示时间和日期。设置里能选 24 小时制、显示秒。

- `component.json` 的 `panel` 字段声明这块面板：入口 `panel.js`、页面宽高(像素)、在 VR 里的默认宽度(米)。别的项都有默认值。
- `panel.js` 是纯 JS，不用构建：默认导出一个 Cordis 插件，是面板的根组件。
  - `ctx.slot.el` 就是整块面板：往里面放自己的元素；它自己的类名(主题、深色)由宿主管，不要改。
  - `ctx.config` 是设置的当前值；在组件页改了设置，这块面板重载，插件拿到新值。
  - `ctx.i18n.locale` 是界面语言，`ctx.i18n.text` 按界面语言取文案(插件写 `inject: ['i18n']`)。
  - `ctx.panel.visible` 是面板这一刻有没有在显示，没在显示时停表；`ctx.panel.hide()` 请显示方收起这块面板。
  - 界面语言和显示状态是响应式的，放在 Vue 的 `watchEffect` 里读，变了会重跑。`vue` 由宿主共享，直接 `import`。
- 卡片和按钮用了宿主的 `.card`、`.icon-btn` 样式和颜色变量，深色、换皮肤会跟着变。

调试：带环境变量 `FOXPANEL_PANELS=1` 启动源码版，在组件页从文件夹加载这个文件夹，时钟显示成一个普通窗口；改了 `panel.js` 保存，窗口自动重载。见 [写一个组件 · 写一块面板](../../docs/develop.md#二写一块面板) 和 [SDK](../../docs/sdk.md)。
