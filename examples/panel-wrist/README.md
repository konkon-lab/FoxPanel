# 手腕时钟

面板组件(`kind: panel`)：一块附着在左手手柄上的小面板，显示时间和日期，抬手看表时才显示。设置里能选 24 小时制。

- `component.json` 的 `panel` 字段声明这块面板：
  - `anchor: "left"`：面板第一次出现时附着在左手的手柄上，跟着手走(`head` 是跟着头显，`right` 是右手，不写是留在空间里)。
  - `glance: true`：只在面板的正面朝向眼睛时显示(抬手看表的姿势)；手垂着时不显示，页面照常在画，抬起来就是这一刻的画面。
  - `width`、`height` 是页面的像素，`meters` 是在 VR 里的宽度(米)：手腕上的面板要小，页面也小，字要大。
  - 这些是面板第一次出现时的取值：之后附着在哪、抬手才显示、宽度、相对手柄的位置都记在显示方的布局里，用户改了以布局为准。
- 附着在手上的面板一开始是锁着的(不会被握把带走)，这只手的射线点不到它，用另一只手指、点。
- `panel.js` 的写法和[时钟](../panel-clock)一样：默认导出一个 Cordis 插件，往 `ctx.slot.el` 里放自己的元素，`ctx.config` 是设置的当前值，
  `ctx.i18n.locale` 是界面语言，`ctx.panel.visible` 是页面这一刻在不在画。

调试：带环境变量 `FOXPANEL_PANELS=1` 启动源码版，在组件页从文件夹加载这个文件夹，它显示成一个普通窗口(附着和抬手才显示在窗口上没有效果，
在远程服务 `panels` 的状态里看得到)；附着的效果要在 SteamVR 里看。见 [写一个组件 · 写一块面板](../../docs/develop.md#二写一块面板) 和 [SDK](../../docs/sdk.md)。
