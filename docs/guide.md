# 使用说明

## 安装

需要 64 位的 Windows 10 或 11，和 SteamVR。

1. 运行 `FoxPanel-Setup-<版本>.exe`：向导里选只给自己装(默认)还是给所有用户装，可以选安装目录。安装目录要用空文件夹，或让向导建的 `FoxPanel` 文件夹(卸载和覆盖安装时整个安装目录会被清空)。
2. 打开 FoxPanel。第一次启动会部署输入法词库，要等一会儿(键盘上显示「输入法部署中…」)。
3. 打开 SteamVR。程序会自动连上 SteamVR，主窗口右下角状态栏的 STEAMVR 亮绿灯；按收起 / 恢复面板的键，面板出现在面前。

第一次连上 SteamVR 时，程序把自己登记进 SteamVR 并设成随 SteamVR 启动；不想要的话，在 SteamVR 设置「启动 / 关闭」里的启动叠加层应用列表中关掉 FoxPanel。

VRChat 里要打开 OSC：动作菜单 → 选项 → OSC → 启用。聊天框默认发到本机 9000 端口，要改的话在 组件 → OSC 的「发送端口」里改。

## 在 VR 里用

| 操作 | 默认键位(Index / Quest / Vive) |
|---|---|
| 收起 / 恢复面板(全部) | 右手 B 双击(Vive 是菜单键双击)；恢复时不在面前的面板放回面前 |
| 快捷面板 1：单独显示 / 隐藏它指向的面板(默认是键盘) | 左手 B 双击(Quest 是 Y，Vive 是菜单键双击) |
| 点击 | 用手柄指着面板按扳机；按住拖动能滚动列表 |
| 移动面板 | 指着它握住握把(按住一小会儿才跟手)，松手时留在那里 |
| 改大小 | 两只手都抓住同一块，拉开或靠拢；松手后记住宽度 |

键位可以在 SteamVR 的手柄设置里改(应用名 FoxPanel；另有一个默认没绑键的「快捷面板 2」)。位置和大小每块面板各记各的，下次打开还在原处。

装了别的面板组件时，它们和键盘一起跟着「收起 / 恢复面板」显示；不想让哪块出现，就在 组件 页关掉它的组件。面板组件可以让自己的面板跟着头显或手柄走，比如手腕上的小面板，抬手看它时才显示。同时显示几块、「快捷面板 1」「快捷面板 2」各指向哪块面板、要不要挡住游戏按键、抓取延迟这些在 组件 → SteamVR 的设置里改。

**键盘上**

- 语言键(空格左边)：开着两种语言时显示「拼/EN」这样，按一下换另一种；多于两种时弹出语言面板；只有一种时变灰。
- 模式键(空格右边)：简 / 繁、漢 / あ / ア 这类，按一下换下一个。
- Shift 按一次管一个字，连按两次锁定；Caps 只影响字母。
- 候选栏：第一个高亮，右边的箭头展开全部候选；PgUp / PgDn 翻页。
- 输入框右边：清空、复制、语音输入(开着语音输入组件时才能按)、发送。
- 右侧面板：快捷设置(输入状态展示、自动送出、PIN 消息、发送到、清除聊天气泡)、小键盘、特殊符号；最右边是粘贴和日夜切换。

**发送到**：快捷设置里列出装着的输出(聊天框、语音合成……)，点一下开或关。

## 主窗口

**仪表盘**：今日费用、近 14 天和本月费用，翻译和语音的快捷设置。

**组件**页：左边是按分组排的组件树，右边是选中组件的详情。

- 详情里能启用 / 停用、改设置、看运行日志和用量、重命名、卸载。语言的详情里能选模式，拼音的详情里能导入搜狗输入法的用户词库。
- 只能用一个的类别(候选栏、输入框、键盘布局、皮肤、翻译)：在详情里点「选用」；停用在用的那个就是这一类都不用。
- 能用多个的(面板、侧栏页、侧栏按钮、语言、输出、输入源)：各自开关；在树里拖动排序(语言的顺序就是语言面板里的顺序)，也可以拖进别的分组。
- 「安装组件」菜单：从市场安装，或选组件的 zip。带代码的组件会提示「能在你的电脑上运行任意程序」，只装信任的来源。
- 预装组件也能卸载。

**市场**页：搜索、安装、更新发布在 npm 上的组件。

**依赖管理**页：给从市场装的组件换版本、全部更新，移除组件。**依赖图**页：正在运行的组件之间的关系。

**日志**页：运行日志。

**设置**页：界面语言、关闭窗口时、以管理员身份运行、主题和缩放、更新、开发者模式(从文件夹加载组件，写组件用，见 [写一个组件](develop.md))。

## 语音合成、语音输入、翻译

这三个预装组件用阿里云百炼，需要你自己的 API Key(在百炼控制台创建，按用量计费)：

1. 组件 → 阿里云 → 填「API Key」并保存。语音合成、语音输入、翻译共用这一个 key。
2. 打开语音合成；「播放到」选给 VRChat 当麦克风的虚拟声卡，「本地监听」可以同时在自己的耳机里听。
3. 要翻译的话，在仪表盘「翻译」卡片上打开开关(或在组件页打开翻译组件的详情点「选用」)，设好翻译成什么语言。开着翻译时，聊天框显示「原文（译文）」，语音合成读译文。
4. 语音输入：输入框的麦克风按钮，按一下开始说，再按一下停；在「语音输入」组件的设置里选麦克风和识别语言。
   - 「跟随 VRChat 静音键」(默认开)：在 VRChat 里取消静音就开始识别，静音就停。
   - 「说完一句直接发送」(默认关)：每说完一句就发出去。和上一项一起开，就是取消静音说话、每句自动发到聊天框并朗读。
5. 用量和费用：组件详情里能看到这个组件今天、最近 7 天、本月的用量和费用；仪表盘上有今日、近 14 天和本月的费用。费用按中国内地价估算，以百炼账单为准。

国际站的 key 要把阿里云组件的「接入域名」改成 `dashscope-intl.aliyuncs.com`。

## 数据放在哪

都在 `%APPDATA%\FoxPanel\`：

| | |
|---|---|
| `config.json` | 设置 |
| `secrets.json` | API Key 等，用 Windows 系统凭据加密 |
| `components\` | 装着的组件 |
| `component-data\` | 组件自己存的数据 |
| `rime\` | 输入法的用户词库和部署文件 |
| `usage.json` | AI 组件的用量 |
| `logs\` | 运行日志文件(位置可以在 组件 → 日志 的设置里改) |

## 卸载

在 Windows 的「已安装的应用」里卸载，或运行安装目录里的卸载程序。

- 安装目录整个删掉，自己放进去的文件也会一起删。
- 数据文件夹 `%APPDATA%\FoxPanel\` 留着：设置、加密保存的 API Key、装着的组件、输入法的用户词库都在，重新安装后接着用。要彻底清掉就手动删这个文件夹。
- SteamVR 里登记的 FoxPanel 留着，在 SteamVR 设置「启动 / 关闭」里的启动叠加层应用列表中关掉它。

## 常见问题

- **键盘没出现**：SteamVR 要先开着；看主窗口右下角状态栏的 STEAMVR 是不是绿灯，再按收起 / 恢复面板的键(右手 B 双击)。还没有的话按「快捷面板 1」的键(左手 B 双击)，再看 组件 页里经典外壳是不是开着。
- **聊天框没反应**：VRChat 要开 OSC；组件 → OSC 的「发送端口」要和 VRChat 的 OSC 接收端口一致(默认 9000)。
- **一直「部署中」**：第一次部署词库较慢；装上或卸载语言后也会重新部署。
- **组件页提示「主进程组件反复崩溃」**：某个带代码的组件出了问题。关掉最近装的组件，再点「重新启动」。
